📌 Project Overview

The Personal Task Manager is designed to help users manage their tasks effectively through a simple and responsive interface. It supports complete CRUD (Create, Read, Update, Delete) operations along with task status tracking and filtering capabilities.

This project was built to strengthen full-stack development skills, including frontend development, backend integration, state management, and data persistence.

---

✨ Features

Core Features

- ✅ Create new tasks
- ✅ View all tasks
- ✅ Edit existing tasks
- ✅ Delete tasks with confirmation
- ✅ Mark tasks as Complete/Incomplete
- ✅ Filter tasks by:
  - All Tasks
  - Active Tasks
  - Completed Tasks

Additional Features

- 📊 Active vs Completed task counter
- ⏰ Overdue task highlighting
- 🔍 Search tasks by title
- 📱 Responsive user interface
- 💾 Persistent data storage
- 📭 Empty state UI when no tasks exist

⚙️ Installation & Setup

Clone the Repository

git clone https://github.com/your-username/personal-task-manager.git

Navigate to Project Directory

cd personal-task-manager

Install Dependencies

Frontend:

cd frontend
npm install

Backend:

cd backend
npm install

Run the Application

Backend:

npm start

Frontend:

npm start

The application will be available at:

http://localhost:3000
