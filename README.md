# Personal Task Manager

A simple full-stack task manager built with Node.js, Express, and vanilla HTML/CSS/JavaScript.

## Features

- Add tasks with title, description, and due date
- View tasks sorted by creation date
- Toggle task completion
- Edit task details
- Delete tasks with confirmation
- Filter tasks by All, Active, Completed
- Search tasks by title
- Persist tasks to a JSON file across server restarts
- Overdue tasks are visually highlighted
- Empty state UI when no tasks are found
- Drag-and-drop reorder tasks

## Run Locally

1. Open the project folder in a terminal
2. Install dependencies:

```bash
npm install
```

3. Start the server:

```bash
npm start
```

4. Open http://localhost:3000 in your browser.
